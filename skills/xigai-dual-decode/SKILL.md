# 习概独门秘籍 · 双层解码

执行 v1.0 方法。以“读者能从问题重建命题，并能退回教材”为目标；不要以篇幅、表格数量或分析术语数量代表深度。

## 先确定输入与边界

1. 读取指定教材版本、目标章节及前后相邻小节。分别识别教材、教师材料、旧稿、公开材料和用户意见；教材负责规范表述，旧稿只是可批判的实验样本。不得将用户评价当作已核查事实。
2. 建立最小来源台账：来源名/版本、文件定位、印刷页、文件页、命题与依据、核查状态。扫描PDF无文本时查看页图/OCR并人工核对关键句；不得拿文件名数字或旧稿索引冒充已核实页码。先校准页码映射，不默认整本恒定偏移。
3. 确定范围和模式：双层秘籍（默认）、考试速记、结构诊断或少量示例。只处理指定范围；创建或测试本Skill不意味着获准生产整章。缺少教材时完成可核部分，列清缺页及影响，不产出伪装完整的教材层或虚构页码。
4. 保留已正确的教材框架、概念边界、页码和考试闭环；不继承旧稿栏目顺序、章眼、全部例子和固定分析表。先读 [evidence.md](references/evidence.md)。

## 先造问题链，再写解释

扫描标题、开篇、转折句、结尾和课后题，区分**教材组织顺序**与**解释时的重建顺序**。用一句话提出章眼，标作〔结构解读〕；它必须解释本章独有张力，不预设每章都是“方向不变、方法可变”。

选择必要的核心命题，形成工作关系图：

现实/历史问题 → 既有回答的适用范围或不足 → 新判断 → 它确定的内容 → 限制条件 → 下一层任务 → 实践提出的新问题。

这是一组候选关系，不是七格必填表。为每条箭头写明连接句与性质：事实依据、概念限定、任务要求、手段保障、实践检验，或仅是编排承接。不要把并列画成递进、相关画成因果、教材先后画成历史先后、规范要求画成现实已实现。允许分叉、回环、并列；禁止为了“推出来”捏造逻辑必然性。

对核心命题执行“删点检查”：删去它，前文哪个具体问题无法回答？后文哪一步失去依据或边界？若答不出，重新判断它是核心、补充还是重复。检查“为什么在这里”：移到前节/后节会丢失何种承接？证据不足时只说明可观察的结构功能，不宣称作者唯一意图。

先形成可读总问题链及教材目录映射，再完成全文，不把内部规划当最终交付。除非用户要求阶段审阅，不必中途索要批准。

## 按命题选刀

读取 [proposition-tools.md](references/proposition-tools.md)。先确定命题在本章不可替代的功能，再选一个主类型，必要时加辅类型；类型决定问法，不是统一输出卡片。

每个核心命题必须具有下列**信息**，但不要逐节复刻小标题：教材准确说什么、在哪里、与什么概念不同；前文解决什么但留下什么，本命题如何补足、开启或限定后文；至少一段实际完成的机制/关系/边界解释；可回到教材的考试表达。不得以“应分析资源和利益”替代实际分析。

按必要性调用三组工具：

**稳定/可变/约束。** 区分方向、原则、制度性质、阶段判断、实现机制、政策工具。说明稳定的依据与时间尺度、旧办法为何不足及调整环节、约束通过何种机制限定选择。基本国情是特定历史阶段内的持续判断，不是永恒常量。不得把“制度”整体归入随意可改或一概不可改。三者要解释关系，不只列三框。

**主体/动力/阻力/协调。** 仅在涉及行动和利益关系时使用。分析推动任务的能力与激励、既有结构造成的阻力、共同目标下成本/节奏/方式分歧；区分目标与工具冲突。有材料支持时解释增量、补偿、规则调整、时间安排如何改变行为及其局限。不能止于名单，也不能默认企业、地方或居民立场一致。缺事实依据则转为明示假设的D类情境或删除，不猜动机。

**现实落地链。** 选择真正成立的环节：判断变化 → 问题排序 → 任务排序 → 资源配置 → 政策/制度工具 → 实施节奏 → 评价指标。每一跳给出机制和证据等级。判断通常约束政策选择范围，不足以唯一推出某个预算、制度或指标；遇分支写明选择条件。不要用箭头掩盖缺证。

## 写成双层阅读，保留考试出口

使用 A〔教材〕、B〔结构解读〕、C〔公开材料 / 现实分析〕、D〔教学推演 / 类比〕四类短标识。它们是证据性质，不是优劣排名；C不自动压过B。证据不同的句子分开标注，禁止含义不明的第五类“〔解码〕”。

秘籍理解允许讨论现实问题、机制、张力和条件。考试模式只保留**规范术语＋教材判断＋概念关系＋题目所需意义**，删去未获题干支持的现实推测、修辞和虚构情境。每个核心命题须有规范出口，可集中成附录，避免两套长文重复。参考答案不自称官方标准答案；助记简称不冒充完整原文。

材料题先识别设问和题干证据，再选择教材命题并解释对应关系；不强制加入主体、成本、反馈。深层推演不能混进需要背诵的规范答案。

首次使用或需校准时读取 [examples.md](references/examples.md)。学习其推理与证据分级，不复制第一章链条到其他章节。

## 让结构可见

读取 [presentation.md](references/presentation.md)。使用“江湖气标题（正式术语/关系）”、有语义的箭头、适量对照表和章级逻辑地图。修辞帮助记忆，正式术语始终保留；“敌友”不得扩散为正文道德标签。

总问题链突出前承后启，正文用连贯解释展开；不把全章拆成孤立精装卡片。无不同维度可比就不用表；长链分段，箭头标关系。删除重复声明、万能术语、同义复述、不承担解释作用的例子。

## 两道逐段闸门与最终验收

每完成一段第二层解码，检查并修订：

1. **泛化测试**：将专名换成企业、外国政府或普通管理。这段若仍几乎原封不动成立，补入真正改变推论的历史条件、章节位置、概念关系；不是多塞几个“中国”。工具可以通用，解释对象和结论不能被抽空。补不出则压为方法旁注或删去。
2. **过度解读测试**：每个“所以/意味着/为了”由什么支持？需要外部事实就核查；仅是条件模型就改标D；无法支持就删除或写“现有材料不足以推出”。禁止猜测隐秘心理，重点检查“必然、唯一、真正意图、已经证明”。

最后执行 [acceptance.md](references/acceptance.md) 六项验收。硬失败先修，不用平均分掩盖。报告实际样本、问题、修订和未验证范围；不要自称整本已验证。缺料一次界定、局部准确标记，不堆免责声明。交付指定产物及简短核查说明，完成范围后停止。
