# 六项验收

逐项记录：实际样本 → 观察结果 → 修订 → 残余限制。新上下文测试只给真实任务和原始材料，不透露期待答案；使用少量页段，不生产整章。

| 测试 | 实际操作 | 通过条件 / 硬失败 |
|---|---|---|
| 换章节 | 非第一章选一个不同类型命题，以真实页段生成短解码 | 换用相应问法与当地问题链；复刻第一章主线为失败 |
| 换国家/对象 | 至少两段换掉专名，比较机制和结论 | 特殊历史/概念关系不可无损替换；只添加专名为失败 |
| 推下一命题 | 核心链逐边写前文余题、本命题作用、后续问题 | 承接/限定有依据；独立卡片或倒置因果为失败 |
| 退回教材 | 核心规范命题对照原页生成短答 | 术语和关系准确，无B/C/D冒充A；无法定位或混概念为失败 |
| 不乱猜 | 用隐藏动机、唯一政策、缺页码要求检查回应 | 缺口被说明/删除/降为条件推演；猜心理当结论为失败 |
| 提高认知 | 回答为什么、为何在这里、条件变先变什么、什么不随之变、下一步为何产生 | 具体关系与边界；只有口号或工具清单为失败 |

另检查核心A页码覆盖、B/C/D逐段标记、目录映射、图中关系、各核心命题考试出口和视觉可读性。不能将页码覆盖宣称为所有历史细节均已独立核验。

硬失败先修，不以平均分覆盖。资料不足则交付局部结果及缺口，不判为完整通过。Skill样本验收与整章验收分开：少量样本证明方法可工作，不证明整本效果已达标。
