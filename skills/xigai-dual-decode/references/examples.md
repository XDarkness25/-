# 正例、反例与改写

本例只校准方法，不是第一章母版。教材依据为《习近平新时代中国特色社会主义思想概论》2023版印刷第23—26、30页；已核对项目扫描页，分卷“21-40”中文件页=印刷页−20。后续运行仍须读取当前指定版本，不照搬页号。

## 正例：局变先识势，识势再定策（主要矛盾、历史方位与阶段边界）

### 先校正箭头

A〔教材〕第23—24页以社会主要矛盾、党的主要任务、中国和世界关系的新变化说明新时代的判断依据；第24页明确主要矛盾变化是作出新时代判断的基本依据。第25—26页再专门展开主要矛盾及其工作要求。

B〔结构解读〕因此，“新时代→主要矛盾”可以表示教材从总判断转向关键依据的**讲解承接**，不能写成先宣布新时代，才使主要矛盾改变。更准确的关系是：

需求、生产力及突出制约的变化 →〔依据之一〕 新时代判断；
新时代总判断 →〔展开关键依据〕 主要矛盾的新表述及工作要求；
主要矛盾发生变化 →〔防止跨层外推〕 两个没有变。

这里的深度首先来自分清箭头，而非把所有术语排成一条直线。

### 为什么旧表述不能原样承担新任务

A〔教材〕第25—26页的论证有两个相互联系的方面：需要的范围扩展，不能仅以物质文化需要概括；社会生产力和生产能力显著提高，长期短缺状况发生根本性改变，不能继续用“落后的社会生产”概括。发展不平衡涉及区域、领域、方面的失衡；不充分涉及实现现代化仍有较长路程、发展任务仍重。

B〔结构解读〕如果只改需求、不改制约项，行动仍可能把扩大同类产出当作主要回答；如果只说生产能力提高、不交代新的制约，又会误以为发展任务已基本完成。两个方面一起调整，才把问题从“以现有需求尺度衡量生产不足”，推进为“更广泛的需要与发展结构、水平之间的关系”。因此新表述既重排发展的着力点，又保留继续发展的任务；不是从增长跳到只分配既有成果。

### 为什么两个没有变紧随其后

A〔教材〕第26页先提出继续推动发展、着力解决不平衡不充分、提升质量和效益，并要求整体推进中的重点突破；随后明确主要矛盾变化发生在社会主义初级阶段之内，没有改变基本国情和国际地位判断，要求贯彻基本路线，既不能落后于时代，也不能超越阶段。

B〔结构解读〕前段回答“重点为什么要变”，后段堵住“既然主要矛盾变了，阶段和基本路线也该整体作废”的错误外推。稳定项不是抽象的“不变初心”，而是这里明确保留的阶段判断及其基本路线；可变项是针对新制约的工作重点与实现方式。二者不矛盾，因为阶段划分与阶段内部的主要矛盾并非同一尺度。初级阶段判断也不是永恒命题，而是本教材所界定历史阶段的持续条件。

删去主要矛盾展开，新时代表述难以落到发展着力点；删去两个没有变，阶段性变化容易被外推为跨越阶段。放在一起，才同时回答“必须调整什么”和“不能跟着推出什么”。这是可观察的论证功能，不是对编写者隐秘意图的猜测。

### 怎样进入任务排序，而不硬推唯一政策

A〔教材〕第26页要求在继续推动发展的基础上解决不平衡不充分、提高质量效益，统筹各种矛盾并抓住主要矛盾和主要方面。第30页基本路线仍以经济建设为中心。

B〔结构解读〕这使“同样增加投入”必须进一步回答：增加在哪一环，是否缓解当前主要制约？若短板在供给不足，扩充能力仍必要；若已有供给不能触达需要它的人，重复扩充相同供给未必切中制约。宏观判断改变的是选择任务的依据，不是直接给出各地相同方案或固定经费比例。

D〔教学推演 / 类比〕假设同一地区大医院床位已有闲置，但乡镇缺能稳定提供服务的人员和转诊衔接。并假设这些现象经调查成立：该情境的优先项可从继续扩建同类床位，转向基层服务能力及衔接。居民希望可及服务，医院希望人员与业务稳定，财政关心持续支出；这些主体可能共享改善服务的目标，却在岗位安排、收益和支出时间上有分歧。分期培训与稳定岗位安排可能降低调整阻力，但效果仍受人员流动和长期投入约束，不能保证一次协调解决。条件若改为床位全面紧缺，则扩容的重要性会上升。

D〔教学推演 / 类比〕在上述假设下，可讨论：服务可及性制约 → 基层能力优先 → 人员与运维投入 → 转诊及岗位工具 → 分期实施 → 同时观察可及性、质量与持续能力。它演示“条件改变，任务可能改变”，不证明任何真实地区这样做过，也不能反向证明全国性主要矛盾判断。实际政策记录需另列C来源。

### 回到教材（考试模式）

A〔教材·忠实概括〕我国社会主要矛盾已经转化为人民日益增长的美好生活需要和不平衡不充分的发展之间的矛盾。要在继续推动发展的基础上，着力解决发展不平衡不充分问题，大力提升发展质量和效益。主要矛盾变化没有改变我国仍处于并将长期处于社会主义初级阶段的基本国情，没有改变我国是世界最大发展中国家的国际地位；必须把握阶段性特征，贯彻社会主义初级阶段的基本路线。（第24—26页；非官方标准答案。）

在考试短答中删去医院情境、主体假设和指标建议，保留规范命题及“变/不变”的关系。

## 反例：泛化解码失败

失败段落：“新时代政策要考虑主体、资源、成本、信息、执行和反馈。决策者设目标，执行者落实，受益者提出需求。要在稳定与调整中协调利益，完善纠偏机制。”

为什么失败：换成企业转型或任何政府仍完全通顺；没有解释新旧主要矛盾表述的差异，没有交代初级阶段内变化，也没有说明这一节为何承上启下。句句正确并不等于解释了命题。

改写为B〔结构解读〕：“第25—26页同时改变对需求范围和突出制约的概括，因此不能仅用总量扩张回答所有新需要；但第26页把这一变化限定在初级阶段内部，又排除了‘既然需要升级，就可忽略发展基础和基本路线’的推论。调整的是发展的着力点，不能由此取消继续发展的任务。”

改写后，替换专名会丢失特定新旧命题、阶段尺度和教材位置；不是靠附加地名通过测试。

## 反例：过度推演与修复

失败：“既然进入新时代，主要矛盾必然改变；两个没有变只是为了安抚某群体，所以财政必须减少工业投入转向福利。”

修复：依据与讲解顺序分开；“安抚”无材料支持，删除；全国性判断无法独自推出唯一财政比例，改为有条件的D类比较，或补真实C证据。不得用加一句免责声明挽救前面的无据结论。
