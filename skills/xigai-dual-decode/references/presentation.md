# 阅读与视觉规范

默认导航建议：章眼与总问题链 → 连贯双层讲解 → 考试出口及必要练习 → 来源索引。不是所有章节固定目录。保留教材目录映射；解释重排时说明。

标题可用“局变先识势，识势再定策（社会主要矛盾与任务重排）”。正式术语始终可见，不连续堆武侠比喻。“谁是敌人，谁是朋友（主体、动力与约束）”只在确有主体关系时用作修辞，正文使用准确主体和制度关系。

图示表达问题/判断/行动、前提/推论/边界、连续/调整等关系。图内保留证据短标与页码，完整来源另列。表层/深层仅指阅读层次，不暗示秘密真意。

箭头标“依据、限定、要求、保障”等关系；章级图允许分支回环。短链用行内→，长链分段，不能把七个长句挤在一行。对照表优先两三栏，过宽则拆表或改段落。

## 文档输出

用户要求DOCX/PDF时调用对应技能并渲染检查。本方法不替代格式工具。默认A4，页边距约2.2cm；正文中文11—12pt，行距1.25—1.4，常规字距；一级标题16—18pt，二级13—14pt，来源不小于9pt。可酌情调整，不能靠压字距、缩字号、密集窄栏塞页。

中文字体使用稳定可用的宋体/思源宋体类正文、黑体/思源黑体类标题。正文深色，最多两种辅助强调色，证据不只靠颜色区分。避免全篇卡片、整页重底色、过多边框。

标题随下段、跨页重复表头，避免表格行断裂、孤标题、裁切、重叠。印刷页与成品页码明确分开。逐页渲染检查中文标点、引号、箭头；解析文本异常须看页面再定性。

## 密度编辑

保留独有条件、前后关系、机制、边界、考试概念。删除仅重复“要统筹、要协调、需核查”的段落。不规定每页图表数量；图已讲清关系，正文补机制而不逐字复述。
