# 命题识别与工具选择

先判断命题解决哪个缺口，再选工具。允许复合类型；下表是编辑候选问法，不是逐节必填表。

| 类型 | 不可替代的分析焦点 | 优先工具 | 常见失败 |
|---|---|---|---|
| 历史任务 | 当时什么未解决，什么条件决定先后，后续继承什么 | 历史条件—障碍—任务 | 今天答案投射为当时唯一可知选择 |
| 道路选择 | 路径在具体中国条件下的适用性、实践积累与选择依据 | 条件比较、实践与路径形成 | 只说因地制宜；虚构失败选项 |
| 历史连续性 | 哪些政治、制度、物质、经验积累延续，什么机制需调整 | 层级拆分、继承与转变 | 连续=无错；发展=全盘否定 |
| 性质与原则 | 概念身份与实现形式如何区别；效率为何不能独自界定性质 | 定义、必要条件、反例边界 | 性质问题变执行效率清单 |
| 历史方位 | 什么阶段变化使旧坐标不足，新坐标如何组织任务 | 变化依据、不同时间尺度 | 新时代=跨越初级阶段；顺序当因果 |
| 主要矛盾 | 需求供给怎样变，何种制约具有全局性，如何重点突破 | 瓶颈、主次关系、任务重排 | 只要质量不要数量；只讲收入差距 |
| 基本国情与约束 | 限制何种外推，怎样约束尺度和速度 | 阶段内变化、能力与承受条件 | 以国情否认需求；国情永恒化 |
| 战略目标 | 目标层级、时间节点、完成条件如何组织任务 | 目标—阶段—必要条件 | 目标推出唯一政策；愿景当已实现 |
| 总体布局 | 领域如何组成事业全局，新增维度解决什么遗漏 | 维度关系、结构演进、统筹与重点 | 平均用力；五位一体降格检查表 |
| 制度保障 | 哪种制度关系提供权力、责任、程序或组织保证，为何需要它 | 制度机制、功能与边界 | 列制度名称就算解释 |
| 行动原则 | 什么能变、凭什么变、不能推出什么 | 稳定/调整、正反情境 | 只说原则性与灵活性结合 |
| 实践成果 | 回应何种原问题，支持何种判断，留下何种任务 | 问题—举措—结果、证据范围 | 成果数量当因果证明 |

战略布局可作复合类型：先辨战略目标与举措，再分析保障关系，不与总体布局混同。面对新类型允许新增问法，不强塞分类。

## 最低解释推进

禁止以“需结合历史”“应分析利益”“要考虑资源”作为解码终点。至少完成一条：

已核事实/教材判断 → 具体关系或制约机制 → 本命题特殊作用 → 有边界的推论。

例如解释“两个没有变”，须说明阶段内主要制约变化为何不等于发展阶段跨越、因而基本路线仍需坚持；不能只列预算、人员、承受能力。

主体分析只在具体问题中展开：资料确定权限与成本如何发生，再讨论何种分担或时序调整可能改变行动。不能预设一切阻力来自既得利益，也不能默认补偿能消除目标冲突。共同目标不保证手段一致；手段分歧也不证明反对总体目标。

## 关系边检查

- 事实依据：支持判断，单个依据未必充分推出总体判断。
- 概念限定：防止错误外推，不是否定前一命题。
- 任务要求：提出应做什么，不等于已做到。
- 手段保障：有利或必要条件，未必充分保证目标。
- 实践检验：注意来源、时段和因果识别，不能宣称唯一原因。
- 编排承接：提出下一问题，不自动构成历史或逻辑必然。

“因此”需要额外事实则记缺口；存在多种后续则写分支及选择条件，不强写唯一下一步。
